# Politica de Seguranca

Nao versione:

- Arquivos `.env`
- Backups
- Bancos de dados
- Hashes de senha
- Fotos de colaboradores
- Comprovantes de entrega
- CPFs, CNPJs reais ou dados pessoais
- Dados biometricos
- Tokens e chaves privadas

Remocoes em branch nao limpam historico Git. Caso dados reais tenham sido expostos, e necessaria limpeza de historico com aprovacao explicita.
